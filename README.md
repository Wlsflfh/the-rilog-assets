# THE Rilog. public image assets

Publicly served SPOTLIGHTS thumbnails and official company logos. Editorial guidelines and credentials are kept outside this repository.

- `logos/<company>/<sha256>.<ext>`: verified original company artwork, with attribution in `logos/manifest.json`.
- `thumbnails/YYYY-MM-DD/<sha256>.png`: 1600×1000 typography thumbnails, added only after validation.
- Publication URLs use `https://raw.githubusercontent.com/Wlsflfh/the-rilog-assets/<full-commit-sha>/<path>`.

Company names and logos remain the property of their respective owners. This repository does not grant rights to third-party trademarks or artwork.
