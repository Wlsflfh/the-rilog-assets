# THE Rilog. public image assets

SPOTLIGHTS thumbnails, reusable company logos and the fixed Personal profile. Guidelines, credentials and unpublished editorial content are kept outside this repository.

- `logos/<company>/<sha256>.<ext>`: company images. Current selections and provenance are in `logos/manifest.json`.
- `profiles/personal/<sha256>.png`: user-provided fixed Personal profile, preserved byte for byte.
- `thumbnails/YYYY-MM-DD/<sha256>.png`: typography thumbnails after validation.
- Runtime publication URLs pin a full 40-character Git commit SHA. Existing asset files are retained when a new selection is added.

Company names and logos remain the property of their respective owners. User-supplied images are labelled as such rather than attributed to an independently verified official download.
